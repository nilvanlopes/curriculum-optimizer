# Vaga: Tech Lead Frontend

## Sobre a Vaga

Estamos em busca de um **Tech Lead Frontend** para liderar nosso time de desenvolvimento frontend. A posição é remota e oferece grande oportunidade de crescimento profissional.

## Responsabilidades

- Liderar e coordenar equipe de 5-8 desenvolvedores frontend
- Arquitetar soluções escaláveis usando React e Next.js
- Tomar decisões técnicas estratégicas sobre stack e padrões
- Mentorar desenvolvedores júnior e pleno
- Garantir qualidade de código através de code reviews
- Implementar e melhorar processos de desenvolvimento (CI/CD)
- Colaborar com Product e Design para definir roadmap técnico
- Otimizar performance de aplicações frontend
- Implementar arquiteturas microfrontend quando necessário

## Requisitos Obrigatórios

- 5+ anos de experiência com React
- 3+ anos de experiência em liderança técnica ou coordenação de equipes
- Experiência comprovada com Next.js e TypeScript
- Conhecimento profundo de arquitetura de software frontend
- Experiência com arquiteturas microfrontend (Module Federation, Single-SPA ou similar)
- Experiência com AWS (Lambda, S3, CloudFront)
- Conhecimento de CI/CD (Jenkins, GitHub Actions, ou similar)
- Experiência com metodologias ágeis (Scrum, Kanban)
- Inglês avançado (leitura técnica e comunicação)

## Requisitos Desejáveis

- Experiência com React Native
- Conhecimento de GraphQL
- Experiência com Docker e Kubernetes
- Certificações AWS
- Experiência com testes automatizados (Jest, Testing Library)
- Conhecimento de design systems
- Experiência com SEO e performance web
- Participação em comunidades técnicas (blog, palestras, open source)

## Stack Técnico Principal

- **Frontend**: React 18+, Next.js 14+, TypeScript, JavaScript ES6+
- **Styling**: Tailwind CSS, Styled Components, CSS Modules
- **State Management**: Redux, Zustand, React Query
- **Arquitetura**: Microfrontends, Module Federation, Design Patterns
- **Cloud**: AWS (Lambda, S3, CloudFront, EC2)
- **DevOps**: Docker, CI/CD, GitHub Actions, Jenkins
- **Mobile**: React Native, Expo (desejável)
- **Testing**: Jest, React Testing Library, Cypress
- **Build Tools**: Webpack, Vite, Turborepo
